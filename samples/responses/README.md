# Оригинальные ответы Open Library

Получены 11 ноября 2026 года прямым HTTP GET. `.json` сохранены из HTTP-ответов без разбора и повторной сериализации. Рядом с каждым ответом находится `.metadata.json`: URL, UTC-время, SHA-256 исходного файла и обнаруженная форма `description`. Метаданные созданы нами и не являются частью ответа API.

| Запись | URL | description |
|---|---|---|
| OL45883W | https://openlibrary.org/works/OL45883W.json | отсутствует, но это `/type/redirect` → OL45804W |
| OL82563W | https://openlibrary.org/works/OL82563W.json | объект с `type` и `value` |
| OL14933414W | https://openlibrary.org/works/OL14933414W.json | отсутствует, но это `/type/redirect` → OL27513W |
| OL45804W | https://openlibrary.org/works/OL45804W.json | строка |
| OL27513W | https://openlibrary.org/works/OL27513W.json | строка |
| OL262758W | https://openlibrary.org/works/OL262758W.json | отсутствует, но это `/type/redirect` → OL27482W |

Явный `null` и настоящая work-запись без `description` не найдены в этих шести ответах. Это не доказательство их отсутствия во всей базе. Для них используются `../synthetic/null.json` и `../synthetic/missing.json`. Отсутствие поля в redirect не выдаётся за отсутствие описания у книги. Дополнительные GET для OL1W, OL2W, OL3W, OL100W, OL1000W, OL10000W вернули ошибки (OL1W — notfound); файлы успешных ответов для них не создавались.

Все четыре файла в `../synthetic/` написаны вручную для краткого стабильного вывода и граничных тестов; они не являются изменёнными или оригинальными ответами API. Некорректные формы JSON задаются также непосредственно в тестах.

Повторный live-запрос может вернуть другую редакцию записи. Не заменяйте сохранённые ответы без обновления метаданных и повторной проверки тестов.
